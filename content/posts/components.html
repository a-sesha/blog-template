Copy what you need from here. Everything below is plain HTML with a class name; there is nothing to install and nothing to learn beyond the class names. Delete this post (or mark it draft: true) when you no longer need it.

Widths

Text sits in a 768 px column. A direct child of the page body can choose a wider slot by class: wide (about 1000 px) for figures and video, full for something that should touch both edges of the window. Because the page is a grid, these never cause sideways scrolling, and on a phone every width collapses to the screen.

<div class="wide">...a figure...</div>
<div class="full">...a banner...</div>

Type

Body text is a humanist sans at 17 px, headings are a light serif, and anything that is data (dates, captions, buttons, diagram labels) is monospace. Links are grey and underlined until you point at them. Inline code, a Ctrl+K key and a highlight are available.

A third-level heading

Second- and third-level headings get an address you can link to; hover one to see the #.

A pull quote is set in the heading face. Use it sparingly, for the one sentence you want a reader to remember.

Figures

A figure sits on faint graph paper that fades into the page. Draw diagrams as inline SVG so the text stays crisp and selectable. Cards have square corners and a hard offset shadow; arrows are thin with an open head; a butter-yellow box is for an annotation.

Colours keep one meaning across a post: if butter is series A in the first chart it is series A everywhere. Put the fill at the 400 level and the outline darker, the same for comparable elements.

Code

# a block of code scrolls sideways instead of wrapping
def smooth(xs, k=5):
    return [sum(xs[max(0, i - k):i + 1]) / len(xs[max(0, i - k):i + 1]) for i in range(len(xs))]

Definitions on hover

Mark a term once and a small card explains it on hover, on keyboard focus or on tap: FiLM and EMA.

Video and images

Put files in content/images/; they are copied to images/. A video gets rounded corners and spans the wide slot:

<div class="wide"><figure>
  <video src="../images/demo.mp4" controls muted loop playsinline preload="metadata"></video>
  <figcaption>Held-out start 0, 300 frames.</figcaption>
</figure></div>

Reusable pieces

Instead of pasting the markup above, you can call it by name. A piece is a small HTML file with blanks in it; calling it fills the blanks, so changing how all your callouts are built means editing one file. The built-in pieces live in theme/components/; a file of the same name in content/snippets/ replaces a built-in one, and any new file there becomes a new piece.

{{pill "new" color=butter}}                     a call with a plain argument and a named one
{{#callout title="Heads up"}} ...HTML... {{/callout}}    a call that wraps content
\{{pill}}                                       a backslash writes the braces literally

Live, written that way:

{{#callout title="From a shortcode"}}This callout is {{#callout}}...{{/callout}}; the title is optional and disappears when left out.{{/callout}} {{#facts}}{{fact value="18" label="components"}}{{fact value="1 file" label="to change a look"}}{{fact value="0" label="dependencies"}}{{/facts}}

{{pill "plain"}} {{pill "teal" color=teal}} {{pill "butter" color=butter}} {{button "A button" href="#reusable-pieces"}} and a {{term "hover definition" title="Defined once" tip="Written as a term call with the definition as an argument."}}.

{{#card variant=strong}}A strong card, wrapping any HTML, including other pieces: {{pill "nested" color=sage}}.{{/card}} {{#quote cite="Someone, somewhere"}}A quotation, with an optional source.{{/quote}} {{#appendix title="Appendix: a collapsible section from a shortcode"}}
